## 快速开始

### 方式一：课堂模式（全班共享排名，推荐上课用）

需要 macOS/Linux 自带的 Python 3，**无需安装任何第三方库**：

```bash
python3 server.py        # 或双击 start.command（macOS）
```

- 自己玩：浏览器打开 `http://localhost:8000`
- 同学加入：连同一 Wi-Fi，打开终端里打印的 `http://<你的IP>:8000`
- 点赞数据存在 `data/likes.json`，清空它即可重置排名

### 方式二：纯静态模式（GitHub Pages / 任意静态托管）

直接把本仓库作为静态网站部署（如 GitHub Pages），**所有游戏都能玩**。此时页面自动进入「本机演示模式」：点赞只保存在各自浏览器里，排行榜不共享。

### 方式三：本地静态服务器

```bash
python3 -m http.server 8000    # 不带点赞接口，自动进入本机演示模式
```

> 注意：直接双击 `index.html`（file:// 协议）打不开，浏览器会拦截数据文件加载，请用上面任意一种方式。

## 想自己做一个这样的展示页？看这里 👩‍💻

这个网站没有任何框架和构建步骤，就是最朴素的 HTML + CSS + JavaScript，非常适合学习改造。整个结构只有四层：

```
snake-gallery/
├── index.html          # 主页骨架：标题 + 三个空容器（导航/卡片墙/排行榜）
├── css/style.css       # 全部样式（糖果色主题，改 :root 里的颜色变量即可换肤）
├── js/main.js          # 全部逻辑（约250行，注释齐全）
├── data/
│   ├── games.json      # 【核心】讲次与游戏清单——加游戏只改这一个文件
│   └── likes.json      # 点赞数据（server.py 读写）
├── server.py           # 可选的点赞服务器（仅 Python 标准库，约100行）
├── games/lecture1/     # 每位同学一个目录，各放一个自包含 index.html
├── assets/             # 游戏用到的图片素材
├── sources/            # 原始 Python 作业归档（移植参考）
└── materials/          # 第一次课堂作业的原始提交文件
```

**数据流只有三步**：`games.json` → 渲染卡片墙和排行榜 → 点赞 POST 给 `server.py` 写回 `likes.json`。

### 加一个你自己的游戏（5 分钟）

1. 在 `games/lecture1/` 下新建文件夹，比如 `games/lecture1/myname/`；
2. 里面放一个**自包含**的 `index.html`（CSS/JS 都内联，不依赖外部文件就能跑）；
3. 在 `data/games.json` 第一讲的 `games` 数组里加一条：

```json
{ "id": "l1-myname", "author": "你的名字", "title": "我的游戏",
  "tags": ["特色1", "特色2"], "path": "games/lecture1/myname/" }
```

4. 刷新页面，你的卡片就出现了，点赞和排名自动生效。

### 游戏页面的约定（照做就不会踩坑）

- 键盘事件挂在 `window` 上，并对方向键/空格调用 `preventDefault()`（否则会滚动外层页面）；
- 画布逻辑分辨率固定，用 CSS `transform: scale()` 适配窗口大小；
- 存档（最高分等）用 `localStorage`，键名加前缀避免和别人冲突；
- 音效用 WebAudio  oscillator 合成，无需音频文件，首次用户交互后再创建 `AudioContext`。

### 想把 Python 游戏搬上网页？

本仓库的 19 个游戏就是从 pygame/tkinter/curses 移植来的，可以对照 `sources/` 里的原始代码学习。核心思路：

| Python | 网页版 |
|---|---|
| `tkinter.Canvas` / `pygame` 绘制 | `<canvas>` + Canvas 2D API |
| `after()` / `clock.tick()` 主循环 | `requestAnimationFrame` |
| 读写本地 JSON 存档 | `localStorage` |
| `winsound` / 合成音频 | WebAudio API |
| 消息弹窗 | HTML 覆盖层 |

### 开新一讲

在 `data/games.json` 里把对应讲次的 `active` 改为 `true`、往 `games` 数组加条目即可，左侧导航和排行榜自动适配——第二讲到第八讲的位置已经留好了。
