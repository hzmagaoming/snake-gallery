# 贪吃蛇小游戏（pygame 版）

《突发事件应对模拟仿真》课后作业 —— 贪吃蛇小游戏。

## 运行环境

- Python 3.8 及以上
- 依赖库：pygame

## 安装依赖

```bash
pip install pygame
```

使用 Anaconda 的同学可改用：

```bash
conda install -c conda-forge pygame
```

## 运行方式

```bash
python snake.py
```

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 控制方向 |
| 空格 | 暂停 / 继续 |
| 1 / 2 / 3 | 切换速度（低 / 中 / 高） |
| H | 菜单中查看玩法规则 |
| 回车 / 空格 | 菜单中开始游戏 |
| Esc | 退出 |

## 玩法与创意设计

在经典贪吃蛇的基础上，加入了两个小创意：

### 1. 限时金苹果

- 普通食物 10 分；食物每 5 秒会变成金色（持续 3 秒），此时吃掉得 30 分。
- 设计意图：制造"要不要冒险去抢"的紧张感，考验玩家对时机的判断。

### 2. 随机道具

每 7 秒在场上刷新一个道具，蛇头碰到即生效：

| 道具 | 颜色 | 效果 | 持续时间 |
|---|---|---|---|
| 减速 | 蓝 | 移动变慢 | 5 秒 |
| 护盾 | 金 | 撞到自己不死亡 | 6 秒 |
| 穿墙 | 紫 | 穿过边界从对面出来 | 8 秒 |

### 其它

- 三档速度可选；
- 顶栏实时显示当前生效中的道具及剩余时间；
- 菜单内按 H 可查看完整玩法规则。
