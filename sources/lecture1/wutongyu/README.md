# EMERGENCY RUN | 应急行动

Python + Pygame 课程游戏。驾驶救援车队搜救群众、携带物资，并到安置点完成转移；携带负载会使车队变长，需要权衡继续搜救与及时撤离。

## 运行环境

- 推荐 Python 3.11，依赖固定为已测试的 Pygame 2.6.1。
- 已验证：macOS / Apple Silicon，Python 3.11.16。
- 需要图形桌面和可写的项目文件夹，不是独立的 .app 或 .exe。
- 当前中文字体优先使用 macOS 系统字体；Windows / Linux 的中文显示尚未验收。

## 安装和启动

先在终端进入本项目文件夹，每次执行一行：

```bash
python -m pip install -r requirements.txt
python main.py
```

使用 Anaconda 的初学者请优先参照交付文件夹中的 `01_先读我_运行说明.txt`，创建或启用 Python 3.11 环境。不要在 Python 3.14 的 base 环境中安装此交付版。

## 基本操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 暂停 / 继续 | SPACE |
| 风险扫描 | E |
| 重新开始 | R |
| 返回主菜单 | ESC |

主菜单的“游戏说明”包含四步救援流程及六类地图图例。“开始行动”先显示灾情任务卡，点击“出发”进入游戏；未完成教学的玩家使用教学布局，完成后也可选择“再次学习玩法”。

## 已实现机制

- 搜救 / 携带 / 安全转移的得分循环，人员和物资在安置点结算。
- 网格碰撞配合车辆视觉插值；移动计时保留余数，渲染目标 60 FPS。
- 四阶段灾情等级：0–60 秒 I；60–120 秒 II；120–210 秒 III；210 秒后 IV。等级仅由难度阶段决定。
- 开局保护、轻量教学、风险扫描和车队负载。
- 安置点里程碑 / 阶段迁移，提前预警并检查可达位置。
- 余震、暴雨积水、通讯中断及限时恢复。
- 求是鹰支援、连续救援奖励和无线电消息。
- 三种随机情景各三套手绘背景；背景装饰不影响碰撞。
- 最高分、救援记录及教学状态保存在 `data/save.json`；缺失或无效 JSON 使用默认值。

## 文件职责

```text
main.py                唯一启动入口
game.py                游戏循环、状态、输入、核心逻辑与界面
config.py              玩法参数、难度阶段与视觉规范
entities.py            状态枚举和对象数据结构
map_art.py             地图与对象图集加载、缓存和绘制
entry_art.py           封面、任务单与说明图例
ui.py                  字体加载
storage.py             JSON 存档
assets/images/         封面、场景图集、对象图集与生成说明
data/save.json         本地存档
requirements.txt       固定第三方依赖
```

资源使用项目相对路径，需与源码一起交付。文件夹可整体移动；不要只发送 `main.py`。
