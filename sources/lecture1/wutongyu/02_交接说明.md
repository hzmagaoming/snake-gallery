## 交付范围

本目录冻结当前确认版本，包含唯一入口、八个 Python 模块、固定依赖、正式图片资源、初始存档和运行文档。没有打包 Python、Conda、虚拟环境、缓存、临时截图或历史游戏版本。源码逻辑与原项目当前版本一致。

交付副本采用全新玩家记录；原项目记录保留不动。运行副本后，副本的分数和教学状态会更新，属于正常行为。

- 封面：`assets/images/menu_cover.png`。
- 地图：`world_rain.png`、`world_earthquake.png`、`world_flood.png`。
- 三个地图图集各为 2×2 区域：左上、右上、左下为三套场景；右下为纸张材质。

- `game.py` 仍同时包含核心控制与部分绘制，符合当前课程项目规模，后续扩展时再按职责拆分。
- 存档是简单 JSON，容错针对缺失/损坏内容；没有数据库、并发保护或写入权限修复。
- 推荐在另一份开发副本继续改动，保留本目录和 ZIP 作为本次交付基线。

## 文件校验

`SHA256SUMS.txt` 记录交付文件的 SHA-256；自身不列入清单。

macOS 在本文件夹内执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

初次解压、尚未运行游戏时应全部显示 OK。运行游戏后 `data/save.json` 可能变化，因此它的校验变化不代表源码损坏。
